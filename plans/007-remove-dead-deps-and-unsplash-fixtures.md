## Why this matters

The Unsplash integration was removed recently, but story and e2e fixtures still reference `images.unsplash.com`. Those URLs can break or confuse maintainers. Additionally, several runtime and dev dependencies (`prop-types`, `luxon`, `pluralize`, `@types/color-convert`) are declared but not imported anywhere in `src/`. Removing them shrinks the install footprint and reduces the attack surface.

- `package.json:187` declares `@types/color-convert` as a dev dependency.
- `package.json:229` declares `pluralize` as a dev dependency.

Leftover Unsplash URLs:

### Step 3: Replace Unsplash fixture URLs

Replace each `images.unsplash.com` URL with a stable local or generic placeholder. The project already uses `https://static.inkling.local/...` for local fixtures.

Suggested replacements:

- `src/components/ui/cards/VideoCard.stories.tsx:188` — replace the `customThumbnail` Unsplash URL with `https://static.inkling.local/v5.0.0/images/publication-cover.jpg` or another local fixture.

The exact replacement URL is less important than removing the `images.unsplash.com` hostname.
